# WEB Assignment # 1 -

### 01 - Flexbox (Q1)
- **flex-container** - `display: flex` se flex context start hota hai
- **flex-direction** - items ki direction row / column set karta hai
- **flex-wrap** - items ko next line par wrap karne ke liye
- **justify-content** - main axis par items ko align karta hai
- **align-items** - cross axis par items ko align karta hai
- **align-content** - multiple lines ke beech space control karta hai
- **flex-item** - container ke andar wale child elements
- **order** - item ka visual order change karta hai
- **flex-grow** - extra space ko lene ke liye
- **flex-shrink** - chota hone par shrink hone ke liye
- **flex-basis** - item ki starting size

### 02 - Positioning (Q2)
- **static** - default position, normal flow
- **relative** - apni jagah se relative move hota hai
- **absolute** - parent ke relative position leta hai, flow se nikal jata hai
- **fixed** - viewport par fixed rehta hai, scroll par nahi hilta
- **sticky** - scroll par fixed ho jata hai

### 03 - Selectors (Q3)
- **simple** - tag, class, id se select karna
- **combinator** - selectors ke beech relation
- **descendant** - andar kahin bhi nested element `div p`
- **child** - direct child `div > p`
- **adjacent sibling** - bilkul next sibling `h2 + p`
- **general sibling** - baad wale saare siblings `h2 ~ p`
- **attribute** - attribute se select `[type="text"]`
- **universal** - sab elements `*`
- **group** - multiple ko ek sath `h1, h2, h3`
- **pseudo-class** - state ke liye `:hover`, `:nth-child`
- **pseudo-element** - part ke liye `::before`, `::after`
