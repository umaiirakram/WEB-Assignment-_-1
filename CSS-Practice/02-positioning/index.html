02 - CSS Positioning Practice

1. Static (Default) - Normal document flow. Top, left properties have no effect.
2. Relative - Positioned relative to its normal position. Moved 20px from top and left.
3. Absolute - Positioned relative to nearest positioned ancestor (relative parent).
4. Fixed - Fixed to viewport. Stays in same place even when scrolling. Check top right corner.
5. Sticky - Becomes fixed when scrolled to top. Scroll to see effect.
