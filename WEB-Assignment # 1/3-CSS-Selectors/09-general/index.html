General Sibling Selector (~)

Selects ALL siblings AFTER an element (same parent). Syntax: h2 ~ p { }

Heading H2

First p after H2 - SELECTED by h2 ~ p

Second p after H2 - ALSO SELECTED (unlike + which only selects first)

Div after H2 - Not p, so not selected

Third p after H2 - ALSO SELECTED (all following p)

P before H2 in code - Not selected (must be after)
